같은 이유로 막힌 자기 도메인 리소스가 더 있는지는 #101 의 선행 실측이 `<head>`

## 2. 검토했다가 버린 갈래

- **`og:image:width/height` 를 상수로 (#103).** 상수는 이미지가 바뀌면 어긋난
  채 통과하고, 그것을 잡는 테스트가 어차피 파일을 파싱해야 한다. 파일에서
  읽되 테스트가 render 와 별개로 IHDR 을 파싱해 대조하고, 가짜 2×3 PNG 로
  유도를 증명한다. Pillow 는 들이지 않았다 — IHDR 은 고정 오프셋 8 바이트다.
- **`og:locale:alternate` 를 계산 키로 (#103).** 값이 여러 개라 `{{t:}}` 마커
  하나로는 안 되고, 마커는 HTML 이스케이프를 걸어 마크업을 낼 수 없다. hreflang
  과 같은 플레이스홀더 방식으로.
- **`<head>` 밖 불변을 영구 테스트로 (#100·#103).** "이전 커밋 대비" 를 테스트로
  적으면 다음 `<body>` 변경마다 고쳐야 하는 스냅샷이 된다. 일회 실측(`</head>`
  이후를 HEAD 와 diff, hunk 위치 확인)으로 닫고 영구 안전망은 재현성 검사.
- **X 문서 라이브 URL (조사).** `developer.x.com` 의 Cards 문서 전부가
  `docs.x.com` 루트로 307 이고 새 경로는 404 다. Wayback 스냅샷으로 읽었다 —
  §3-1. Discord 는 공식 문서가 없어 「확인 불가」로 뒀다.
- **`docs/browser-smoke.md` 의 파일명에 도구 이름.** 도구는 그 문서가 정하지
  않는 것이라 이름에 넣으면 문서가 자기 범위를 어긴다.

## 3. 레포 밖에서 확인된 것

### 3-1. OG 소비자의 공식 문서 (조사 보고 요약)

문서에 들어간 것(폴백·robots·형식)은 `docs/seo.md` 에 있다. 들어가지 않은 것:

- **X Cards 문서는 서로 다르다.** Tag Reference 는 "Either twitter:site or
  twitter:site:id is required", Summary Card with Large Image 문서는
  `twitter:site` Required=No. 둘 다 두지 않았고 결정은 후자 쪽이 아니라 「기존
  값에서 유도되는 것만」이다.

- **Slack 은 robots.txt 를 무시한다**("We do not currently honor robots.txt
  files"). 카카오는 `og:*` 만 읽고 robots·`twitter:*` 언급 없음. Discord 공식
  문서 없음.
- **검증 도구.** Meta Sharing Debugger 는 URL 입력으로 가능(로그인). X Card
  Validator 의 현재 상태는 확인 불가. Kakao 는 캐시 삭제 도구만 확인.
