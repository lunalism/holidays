## 2. 검토했다가 버린 갈래

- **ubuntu-latest 유지(B)와 26.04 명시 전환(C).** B 는 이행 기간에 run 마다 이미지가
  달라지고 첫 26.04 배정이 정기 발행 run 일 수 있다. C 는 26.04 실측이 없다.
- **NW·HE 에 이미지 스트림 해시.** 두 주의 PDF 는 정적 파일이라 재수령 sha256 이 같다 —
  #110 갈래는 파일이 결정적이지 않을 때만(§6-3).
- **"무개정" 판정어.** 2015 이후(NW)·2019 이후(BE)는 색인·검색으로 닫았고 한계가 있다.
  구독자 문장에 판정을 싣지 않는다(§6-2).
- **포털 API 의 인증 절차 재현.** HE·BE juris 포털의 `/jportal/wsrest/recherche3/` 는
  인증 없이 `security_notAuthenticated` 로 거절한다. 앱 내부 로그인 흐름을 흉내 내는
  것은 우회라 멈췄다.
- **berlin.de 재요청.** 식별 User-Agent·간격을 둬도 429 가 돌아왔다. 요청을 끊고
  PARDOK·Wayback 으로 갈음했다.
- **PARDOK 검색 요청 JSON 을 손으로 짜기.** 형식이 맞지 않아 빈 응답이었다. 공개
  화면을 브라우저로 쓰는 쪽으로 바꿨다.
- **DTSTAMP 를 바뀐 이벤트에만 새로 찍기(#115 선택지 2·3).** 사후 편집은 `build()`
  결과가 아니게 되고, 렌더러 변경은 `core/ics.py` 라 범위 밖이다.
- **옮긴 보고의 정정.** 날짜가 박힌 기록이라 고치지 않는다. 예외는 #114 의 세션 URL
