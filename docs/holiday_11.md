## 2. 검토했다가 버린 갈래

- **합집합 de.ics (B안)**: 16주 어디든 쉬면 포함(20건). BY 사용자에게
  안 쉬는 날이 뜨는 신뢰 훼손 + 지자체 단위 항목 4개의 포함 판정 불능.
- **주별 피드 우선 (C안)**: 소스 16벌 문제가 전량 복귀, 절단 무산.
- **영어 token**: 독일은 라틴 문자라 kr 의 영어 우회가 불필요. 법조문
  명칭 토큰이 추적성도 좋다.
- **하니스의 격리 실행**: 지시였으나 CC 의 [대체]를 수용 — CI 가 테스트
  안에서 네트워크로 패키지를 받는 구조는 재현성 위반. dev 그룹의 검증된
  0.102 를 importorskip 로. CI 스킵 불가는 Codex 항목 5로 확인됨.
- **머지 직후 workflow_dispatch 실측**: 원복 로직은 기존 경로 그대로고
  9/7 schedule 이 이틀 뒤라, dispatch 를 돌리면 "관찰 하나에 변수 하나"가
  깨진다. 9/7 이 여섯 피드 체제 첫 자동 실행을 겸한다.
- **타국 병렬 착수**: 방에서 프랑스·스페인·미국·영국·이탈리아 요청이
  나왔으나 전부 기각. 미국(연방/주 이중), 영국(4구성국), 프랑스
  (알자스-모젤 특례) 각자 함정이 있고, 독일 구조 검증이 먼저다.
  Issue #40 코멘트에 "독일 이전에 다른 나라를 시작하지 않는다" 명시.
  타국 개별 이슈 사전 생성도 기각(착수 계획 없는 이슈는 부채).
